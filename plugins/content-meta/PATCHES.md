# نسخة مرقَّعة من `@quartz-community/content-meta@0.1.0`

هذا المجلد **نسخة حرفية** من الحزمة المنشورة على npm، عليها ثلاث رقع لا رابع لها.
وتُستعمل عبر `"@quartz-community/content-meta": "file:./plugins/content-meta"` في
`package.json`، فيبقى اسم الحزمة ومسار استيرادها كما هما، ولا يتغيّر شيء في
`quartz.config.yaml`.

> **عند تحديث الحزمة يومًا:** انسخ `dist/` من النسخة الجديدة، ثم أعِد الرقع الثلاث
> أدناه بنصّها على الملفَّين `dist/index.js` و`dist/components/index.js` (وهما
> متطابقان بايتًا ببايت)، ثم شغّل `.\check-custom.ps1` — ففيه فحصٌ لكلٍّ منها،
> وفحصٌ سادسٌ على **الناتج المبنيّ** لا على المصدر.

## العطب الذي جاءت له

كان يخرج سطر بيانات الصفحة هكذا:

```
٠٧ أغسطس ٢٠٢٦10 دقائق للقراءة
```

وهذا **ثلاثة أعطاب في سطر واحد**، لا عطبٌ واحد. وأصلها كلّها أنّ الحزمة كُتبت
لصفحة تُقرأ من اليسار وأرقامُها لاتينية:

1. **نظامان من الأرقام في سطر واحد.** فـ`toLocaleDateString("ar-SA")` يعطي أرقامًا
   **هندية** (`٠٧ … ٢٠٢٦`)، ووقتُ القراءة يُبنى بـ`${minutes}` فيخرج **لاتينيًّا**
   (`10`). والهندية عند خوارزم ثنائيّ الاتّجاه صنف `AN` واللاتينية صنف `EN`، وهما
   لا يندمجان في مسير واحد.
2. **وأثرُ ذلك تداخلٌ مادّيّ لا مسافةٌ ناقصة.** فالخوارزم يقطع محتوى العنصرين
   شُذَرًا ويعيد ترتيبها، فيخرج صندوق كلٍّ منهما متّحدًا مع الآخر. وقياسُه في
   متصفّح حقيقيّ: `<time>` يشغل `[608.3 → 742.0]` و`<span>` يشغل `[519.4 → 658.4]`
   — أي **تداخلٌ بخمسين بكسلًا**، لا فراغٌ مفقود.
3. **والفاصل كان عنصرًا وهميًّا** (`::after { content: "," }`)، وهو **لا يُنسخ** مع
   النصّ ولا يبلغه قارئ آليّ. فما نسخه القارئ من الصفحة `٠٧ أغسطس ٢٠٢٦10 دقائق`
   بلا فاصلة، وإن كانت الفاصلة تُرسَم.
4. **والهامش على جهة مادّية** (`margin-right`)، وهو في صفحة تُقرأ من اليمين يذهب
   إلى **حافة الصفحة** لا بين العنصرين. فوجوده وعدمه سواء.

## الرقعة ١ — أرقام لاتينية في التاريخ

**الملفّ:** `dist/index.js` و`dist/components/index.js` (في نصّ `utils/dist/date.js`
المضمَّن).

```diff
  function formatDate(d2, locale = "en-US") {
-   return d2.toLocaleDateString(locale, {
+   const latnLocale = locale.includes("-u-") ? locale : locale + "-u-nu-latn";
+   return d2.toLocaleDateString(latnLocale, {
```

**العلّة:** توحيد نظام الأرقام في السطر، فهو أصل التداخل. و`-u-nu-latn` امتداد
Unicode في وسم اللغة يبدّل نظام الأرقام **ولا يمسّ التقويم ولا اسم الشهر**؛ وقد
قيس ذلك: `resolvedOptions().calendar` يبقى `gregory` قبل الرقعة وبعدها، ويخرج
`07 أغسطس 2026`.

**ولماذا لا يُغيَّر `locale` في `quartz.config.yaml` إلى `ar-SA-u-nu-latn`؟** لأنّ
مفتاح i18n في الحزم كلّها مطابقةٌ حرفية: `locales[locale] || en_US_default`. فأيّ
لاحقة تُضاف تُسقط العربية إلى **الإنجليزية** في كلّ مكوّن يقرأ نصًّا مترجمًا —
البحث، والوسوم، وسطر القراءة نفسه. فالرقعة تفصل بين الأمرين: `cfg.locale` يبقى
`ar-SA` للترجمة، واللاحقة تُضاف لتنسيق التاريخ وحده.

## الرقعة ٢ — فاصلٌ نصٌّ حقيقيّ لا عنصرٌ وهميّ

**الملفّ:** الملفّان نفسهما، في `src/components/ContentMeta.tsx`.

```diff
+ const separator = (cfg.locale || "").startsWith("ar") ? "، " : ", ";
+ const children = options.showComma ? segments.flatMap((seg, i2) => i2 > 0 ? [separator, seg] : [seg]) : segments;
- return u2("p", { "show-comma": options.showComma, class: classNames(displayClass, "content-meta"), children: segments });
+ return u2("p", { "show-comma": options.showComma, class: classNames(displayClass, "content-meta"), children });
```

**العلّة:** أنّ الفاصل يصير **جزءًا من النصّ**، فيُنسخ مع الصفحة، ويبلغه قارئ الشاشة
ومفهرسُ البحث. و`،` هي **الفاصلة العربية** (`،`) لا اللاتينية، فالصفحة عربية
وعلامتها علامتُها. والاختيار معلَّقٌ بـ`cfg.locale`، فلو صار الموقع بلغة أخرى يومًا
عاد الفاصل لاتينيًّا من نفسه.

## الرقعة ٣ — عزل الاتّجاه، وإسقاط الهامش المادّيّ

**الملفّ:** الملفّان نفسهما، في نصّ `styles/contentMeta.scss` المضمَّن.

```diff
  .content-meta { margin-top: 0; color: var(--darkgray); }
- .content-meta[show-comma=true] > *:not(:last-child) { margin-right: 8px; }
- .content-meta[show-comma=true] > *:not(:last-child)::after { content: ","; }
+ .content-meta > * { unicode-bidi: isolate; }
+ .content-meta[show-comma=false] > *:not(:last-child) { margin-inline-end: 0.5em; }
```

**العلّة:** أنّ `unicode-bidi: isolate` تجعل كلّ عنصر **مسيرًا مستقلًّا** لا يُقطع
ولا يُخلط بجاره، فيستحيل التداخل بنيةً لا اتّفاقًا. وهذا هو أصل الإصلاح؛ والرقعتان
قبله تُحسِّنان المظهر، وهذه وحدها تمنع العطب من العود لو دخل السطرَ رقمٌ من نوع
ثالث يومًا.

و`::after` حُذف لأنّ الرقعة ٢ أغنت عنه، ولو بقي لتكرّرت الفاصلة. و`margin-right`
حُذف لأنه يذهب إلى الحافة في RTL، وبقي `margin-inline-end` **لحالة
`show-comma=false` وحدها** — إذ لا فاصل فيها، فيلزم فراغٌ يمنع التلاصق.

## القياس، لا التقدير

الحكم في هذا الباب لا يصحّ بالنظر، لأنّ العطب في **موضع الصناديق** لا في نصّها،
ولأنّ الفاصلة `::after` تُرسَم ولا تُنسخ — فتبدو موجودة وهي غائبة عن كلّ آلة.
فقيست الحالتان في متصفّح حقيقيّ بـ`getBoundingClientRect`:

| | قبل | بعد |
|---|---|---|
| النصّ كما يُنسخ | `٠٧ أغسطس ٢٠٢٦10 دقائق للقراءة` | `07 أغسطس 2026، 10 دقائق للقراءة` |
| `time` | `[608.3 → 742.0]` | `[630.7 → 750.0]` |
| `span` | `[519.4 → 658.4]` | `[516.1 → 622.3]` |
| بينهما | **تداخل 50.1px** | **فجوة 8.4px** |

ثم فُحص الناتج المبنيّ كلّه: **833 صفحة من 833** فيها تاريخٌ لاتينيّ وفاصلٌ نصّيّ،
وصفرٌ فيها رقمٌ هنديّ، وصفرٌ بلا فاصل.

## تغييرٌ رابع لا يمسّ السلوك

حُذف من `package.json` حقلا `scripts` و`devDependencies` (أربع عشرة حزمة: eslint ·
tsup · vitest…). وعلّته أنّ npm يثبّت اعتماديات التطوير لأيّ حزمة محلّية (`file:`)،
و`dist/` مبنيّ أصلًا. و`reading-time` كانت فيها، وهي **مضمَّنة في `dist/` نفسه**
فلا تُنقل إلى `dependencies`.
